# Amanda Growth AI — MVP

## Executar localmente
1. Instale Python 3.10 ou superior.
2. Abra o terminal nesta pasta.
3. Execute:
   `pip install -r requirements.txt`
4. Inicie:
   `streamlit run app.py`

Os valores iniciais foram preenchidos a partir dos prints enviados e podem ser editados na barra lateral.
Este MVP não se conecta automaticamente ao Instagram. Integração futura depende da API oficial, permissões e autorização da conta.
